# TechTalk Desi — Cinematic Tech Reels Creator Kit

Create research-backed, technically accurate, cinematic technology Reels with ChatGPT and the Claude website.

## Repository contents

This repository contains only the master prompt and the six individual skill ZIP files.

| File | Purpose |
|---|---|
| `prompt.txt` | The only master prompt. Upload this file to your ChatGPT Project. |
| `glass-skill-proper.zip` | Glass custom skill for Claude |
| `ledger-skill-proper.zip` | Ledger custom skill for Claude |
| `pop-skill-proper.zip` | Pop custom skill for Claude |
| `sketch-skill-proper.zip` | Sketch custom skill for Claude |
| `terminal-skill-proper.zip` | Terminal custom skill for Claude |
| `volt-skill-root.zip` | Volt custom skill for Claude |

Each skill is provided as a separate ZIP file. Download the repository and you will have all six ZIP files individually. 

## Complete workflow

### 1. Set up the ChatGPT Project

1. Open ChatGPT and create a Project named **TechTalk Desi — Reel Creator**.
2. Open the Project's Sources and upload the `prompt.txt` file from this repository.
3. Start a chat inside that Project.

Use `prompt.txt` as the only source prompt. 

### 2. Request a topic in ChatGPT

Send the topic in the Project chat. For example:

```text
New topic: How to design a production-ready AWS architecture
Generate all the things according to source file.
```

Another example:

```text
New topic: Jenkins vs GitHub Actions — Architecture Comparison
Generate all the things according to source file.
```

ChatGPT will follow `prompt.txt` and create the content in its specified order:

1. Key audience insights
2. Selected text hook
3. Selected verbal hook
4. Complete Roman-script Hinglish narration
5. Retention analysis
6. Topic-specific Claude video-generation prompt
7. SEO keywords
8. Instagram caption
9. Hashtags

The narration is designed for a 60–120 second Reel. Check technical claims and current service details before publishing.

### 3. Upload the six skills to the Claude website

Use the Claude website at [https://claude.ai](https://claude.ai). Do not use Claude Code for this workflow.

For each of the six ZIP files in the repository:

1. Open Claude and go to **Customize → Skills**.
2. Select **+ → Create skill → Upload a skill**.
3. Choose one skill ZIP file from the downloaded repository.
4. Complete the upload.
5. Repeat these steps for the remaining five ZIP files.
6. Make sure all six uploaded skills are enabled in your Skills list.

Upload these six files separately:

- `glass-skill-proper.zip`
- `ledger-skill-proper.zip`
- `pop-skill-proper.zip`
- `sketch-skill-proper.zip`
- `terminal-skill-proper.zip`
- `volt-skill-root.zip`

If the Skills area is unavailable, check that **Code execution and file creation** is enabled under Claude **Settings → Capabilities**. Skill availability can depend on the account or organization settings.

Official instructions: [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

### 4. Generate the voiceover

1. Copy only the complete Hinglish narration from ChatGPT.
2. Send that narration to the text-to-voice WhatsApp contact used in your workflow: **+1 928-414-9863**.
3. Download the generated voiceover audio.
4. Listen to the audio and confirm that the pronunciation and complete narration are correct.

Confirm that the contact is still active and trusted before sending anything. Do not send passwords, API keys, or private information.

### 5. Create the video using Claude.ai

1. Open [Claude](https://claude.ai) and start a chat.
2. Attach the topic-specific **Claude video-generation prompt** from ChatGPT.
3. Attach the generated voiceover audio file.
4. Include the exact complete Hinglish narration as the transcript.
5. Ask Claude to use the six uploaded skills where they are relevant to the topic.
6. Ask Claude to create the complete vertical video, synchronize the visuals to the supplied audio, and check the final output.

The supplied audio is the narration source. Claude must not rewrite the narration or generate a replacement voiceover. The final video should follow the prompt's vertical 9:16, 1080×1920 requirements and include the `@techtalk.desi` closing end-card.

Claude should be honest about any capability, rendering, file-size, or tool limitation. Uploading skills does not by itself provide a complete video-rendering application or guarantee that every video can be rendered inside the Claude website.

### 6. Continue after a Claude usage limit

If Claude reaches its usage limit, wait until Claude allows you to continue. Reopen the same conversation and use Claude's built-in **Continue** button. Keep the same conversation and attached project files so the existing work remains available. Do not start the entire video again unless Claude indicates that the previous work is unavailable.

## Final brand requirement

Every finished Reel must include the **@techtalk.desi** closing end-card and a natural follow invitation in the narration, following the single spoken username-mention rule in `prompt.txt`.
